# Achievement Labs 1.0.6 — fork.2

Includes all previous fork upgrades and the Dishonored Definitive Edition Xbox One mapping work.

- Restores all 80 Dishonored Xbox achievement IDs by matching exact unique achievement names to the PC edition, correcting 74 misplaced recipes and adding six previously absent Brigmore Witches candidates.
- Uses package-derived ByMyHandOnly and TimeManager criteria for By My Hand Alone and Time Management. The user reported both achievements unlocked successfully on Xbox.
- Adds six requested Xbox-only direct name candidates: Mostly Flesh and Steel, Wall of Sparks, Manipulator, Art Dealer, Mrs Pilsen's Remorse and All Come To Ruin. These six still require individual Xbox confirmation. Mrs Pilsen's matching name was already an old alternative.
- Adds a read-only audit covering all 397 enabled local catalogue titles, 15,932 raw recipes and 30,907 request variants. Reports potential Prey ID mismatches, ineffective Halo MCC metadata replacements and incompatible raw recipe/template pairs. The other games' recipes are unchanged pending review.
- Retains all library, DLC grouping, completion indicators, queue, token, title-spoofer, export, notification and updater upgrades from fork.1.

## Validation and limits

Windows regression tests, upstream updater checks and self-contained executable build passed for 093f12bbe75ac5710ef32983f48982ee18696913. The merged release source has the identical Git tree. Tests validated 15,731 usable mappings and 30,383 strict-JSON payloads without sending live Xbox requests.

This release is not a claim that every event has been live verified. Internal game enum names do not alone establish Xbox collector criteria. The six extra Dishonored direct candidates and six PC-backed Brigmore Witches additions remain unverified unless separately confirmed.

The executable reports version 1.0.6.2 and the GitHub release tag is v1.0.6-fork.2. Automatic update metadata includes its version, size and SHA-256.

The existing Xbox 360 profile-signing dependency remains unavailable; this release does not enable those disabled profile modifications. The Windows executable is unsigned.
