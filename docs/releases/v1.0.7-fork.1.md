# Achievement Labs 1.0.7 — Combined Upgrade (fork.1)

Combines upstream v1.0.7 with the fork's custom features and reviewed fixes. Windows executable version: **1.0.7.1**.

- Library **Open stats**, Global % achievement sorting, artwork, Store-link-to-Title-ID lookup, expanded event stats and persistent multi-title Build Queues from upstream.
- Retains DLC/base-game sections, completion indicators and colours, library sorting, exports, queue controls and delays, notifications, spoofer status/timers, window settings, reviewed edition mapping fixes and Minecraft Xbox One's working hosted route.
- Fixes event catalogue updates for the larger published **Events.zip**. Validates release archive integrity and additions, preserves existing mappings and cached data on failure, and reports clearer errors.
- Library refresh shows download progress when available, stages, title counts and elapsed time.
- Fixes the library Mythic icon overlapping Title IDs by giving it a separate layout column.
- Retains explicit connected-account token retrieval and manual token entry. Experimental background token capture is not included.

The published executable is the unchanged artifact from successful Windows build [38756041517](https://github.com/thevampirebat/achievement-labs/actions/runs/38756041517). Offline enhancement, catalogue, edition, updater and UI checks passed. Live account/service behaviour is not verified by those offline checks.
