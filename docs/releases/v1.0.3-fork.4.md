# Achievement Labs — All fork upgrades (fork.4)

This cumulative Windows x64 release includes the upgrades from PRs #1–#8. Download **AchievementLabs.exe** from Assets. Existing settings and saved queues are retained.

## New in fork.4

- A separate title spoofer tile alongside Auto Unlock queue status, showing the actual spoofed title and ID, session hours, last heartbeat and Xbox-recorded playtime. The playtime display reuses the existing reader without extra Xbox requests.
- Open the title spoofer or stop spoofing directly from its Auto Unlock tile.
- A live **HH:MM:SS timer** on both the Title Spoofer page and Auto Unlock's spoofer tile. Both displays update together, reset for a new session, retain the final duration after stopping and continue past 24 hours.
- Native **Windows notifications** for enabled unlock-failure alerts and unexpected spoofer stops. Heartbeat HTTP errors, request failures and timeouts remain visible after stopping. Manual stops and app shutdown do not trigger failure alerts.
- Saved Windows notification and spoofer-stop alert toggles in Settings, plus **Test Windows notification**. Clicking a native alert opens or activates the app.

## Earlier upgrades included

- Retry mapped event achievements and multi-select batch unlocking; achievement name sorting, filtering and scroll-crash fixes.
- Ghosts Xbox One base-game/DLC sections with green dividers and corrected DLC event mappings, including Hat-Trick.
- Reviewed edition mappings for Infinite Warfare, Modern Warfare Remastered and The Escapists: The Walking Dead. Ambiguous mappings remain disabled.
- Export all achievements with progress, pause/resume and skipping previously scanned titles.
- Concurrent Auto Unlock and title spoofing, available title lookup, Xbox-recorded playtime and heartbeat diagnostics.
- Green completed queue rows, scrolling during unlocking, saved queues loaded for review, queue-entry removal and manual saving of custom delays.
- Separate queue status with countdown, estimated remaining duration and finish date/local time; optional failure notifications and stop-on-failure.
- A game-level Open Auto Unlock shortcut and selectable game titles for copying.
- Live session-token use in Auto Unlock, restored edition mappings when loading saved queues, and optional account-matched token refresh with one retry for missing tokens or HTTP 401/403.
- Windows event-token retrieval matched to the connected Xbox account; retrieved tokens remain visible in the masked paste box after saving.
- Remembered library A–Z, Z–A and Last Played sorting, with automatic refresh for Last Played.
- Missing-total scans check one title at a time alongside Auto Unlock, retry rate limits, try alternate endpoints and exclude challenges.
- Shared catalogue of **937 verified definition totals**, matched by Xbox Title ID and platform, bundled for offline use and checked online with a 24-hour cache. Each account keeps its own unlocked progress.
- Export verified totals without account identifiers, tokens or unlocked counts. The previous Export totals report option has been removed.

## Validation

All nine offline regression groups and the self-contained Windows build passed in [Actions run 37514873136](https://github.com/thevampirebat/achievement-labs/actions/runs/37514873136), including actual-window timer bindings, changing seconds, new-session reset, sessions longer than 24 hours, notification routing and preference persistence. Release source `4b11ffb1f3f5d2363a26ece7f16123c6af0d1eca` has the same tree as tested build source `4855d7a0041b8064648b7038fe76b713acc79e04`. Publication verifies the executable's SHA-256 checksum.

Native Windows notification delivery can be checked on your PC using Settings → Test Windows notification. Actual Xbox achievement credit and account broker availability require PC testing; the offline checks send no live unlock requests. Gaming Services cache token retrieval remains experimental.

The executable is unsigned and requires Windows 10 build 19041 or newer. The underlying application version remains **1.0.3**; **fork.4** identifies this cumulative fork release. GitHub supplies source ZIP and tarball downloads automatically.
