# Achievement Labs — Event catalogue update (fork.5)

This cumulative release retains all previous fork improvements and adds the public event catalogue from the uploaded achievement-labs-1.0.5.zip. The application source baseline remains 1.0.3; this update imports the catalogue rather than replacing the app with upstream 1.0.5 code.

- 400 title blocks, including 95 additions; 15,944 supplied achievement mappings.
- The public catalogue and standalone title templates are now bundled, so the app uses this snapshot without waiting for the remote catalogue service to update. Manual unlocking and Auto Unlock share this provider.
- 43 supplied mappings for 7 Days to Die (Xbox One, Title ID 60633334). Live achievement credit has not been verified.
- Retained Ghosts and edition-specific ID corrections and payload signature guards.
- Converted 608 whole-body requests to ordinary replacements with standalone templates, preserving their parsed payloads. Corrected 48 metadata fragments that included a duplicate property label.
- All title blocks precede SupportedTitleIDs. Incomplete recipes are excluded from available IDs; direct requests cannot bypass validation. Outgoing payloads are serialized as strict JSON.
- Public title metadata is generated from the bundled snapshot. Existing saved queues, settings and account progress remain separate from catalogue data.

All earlier upgrades are included: achievement retry and multi-selection, Ghosts DLC grouping and mapping fixes, export-all progress/resume, library sorting and shared totals, token display/account matching, queue review/removal/custom delays/failure controls, concurrent spoofing, Windows notifications and live timers on both pages.

Validation results and the Windows build will be recorded here before publication. Offline tests send no live Xbox requests. Native notifications and live Xbox achievement credit require PC testing.
