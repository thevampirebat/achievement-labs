# Achievement Labs — All fork upgrades (fork.3)

This cumulative Windows x64 release includes the upgrades from PRs #1–#6. Download **AchievementLabs.exe** from Assets. Existing settings and saved queues are retained.

## New in fork.3

- One **Open Auto Unlock** shortcut in the game toolbar, with the game's title ID filled in.
- Selectable game titles for copying.
- **Save queue delays**, optional failure notifications, and an option to stop on a failed achievement.
- Optional **Refresh event token and retry** for missing tokens or event HTTP 401/403 failures. Refresh matches the connected Xbox account and retries the same achievement once; stopping cancels the retry.
- Auto Unlock uses the live session token and the same event sender as the manual achievements tab. Event detection checks all achievement requirements. Restored queues load reviewed edition mappings before submitting, fixing the “Load or refresh this game's achievements” error.
- **Fill missing totals** checks one title at a time, can run alongside Auto Unlock, retries rate limits, tries the alternate endpoint for empty/404 responses, and excludes challenges from permanent totals.
- A shared catalogue of **937 successful definition totals**, matched by Xbox Title ID and platform, is bundled for offline use. Library connection/refresh checks the public online catalogue, with a 24-hour cache. Xbox/local counts take priority and each account retains its own unlocked progress.
- **Export verified totals** includes earlier cached successes without unlocked counts, XUID or tokens. The previous **Export totals report** option has been removed. No account data is automatically uploaded.

## Earlier upgrades included

- Retry already-unlocked event achievements where reviewed mapped data exists.
- Achievement checkbox multi-selection, Select all/Clear and sequential batch submission.
- Achievement A–Z/Z–A sorting, filtering, selection preservation and scroll-crash fixes.
- Ghosts Xbox One base-game/DLC sections with green dividers and pack filtering; corrected DLC event mappings including Hat-Trick.
- Reviewed edition remaps for Infinite Warfare, Modern Warfare Remastered and The Escapists: The Walking Dead. Ambiguous mappings stay disabled and unexpected catalogue/payload changes stop submission.
- Export all achievements with progress, pause/resume and skipping already-scanned titles.
- Xbox-recorded playtime in hours/minutes and heartbeat diagnostics.
- Auto Unlock and title spoofing can run together; title lookup remains available.
- Completed queue rows highlighted green and the queue remains scrollable during a run.
- Load saved queues for review and remove entries while stopped.
- Library A–Z, Z–A and Last Played sorting with remembered choice and automatic refresh.
- A separate Auto Unlock status tile with countdown, estimated time remaining and finish date/local time.
- Windows event-token retrieval matched to the connected Xbox account; retrieved tokens remain visible in the masked paste box after saving.
