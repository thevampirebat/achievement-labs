# Achievement Labs unofficial fork — mobile update .18

This is an independently maintained, unofficial fork of [Achievement-Labs/achievement-labs](https://github.com/Achievement-Labs/achievement-labs).

Feature contribution: [upstream PR #22](https://github.com/Achievement-Labs/achievement-labs/pull/22). App updates/downloads use the vampirebat fork; event JSON/catalogue updates continue to use Achievement Labs.

## Android 0.6.13 (version code 21)

- Enable all 50 reviewed Xbox One achievements for Modern Warfare Remastered (title 2154930), replacing the mobile edition-guard message with mapped event actions.
- Translate the legacy PC-keyed catalogue to Xbox achievement IDs; accept a corrected Xbox-keyed catalogue without double remapping.
- Check the full ID set and ordered event signatures before enabling the title. Changed IDs, service/title identity, event properties or request structure keep the whole title disabled pending review.
- Preserve all other existing mobile templates, mappings and edition guards.
- Signed with the same permanent Android certificate as 0.6.12 for installation as an update.

## iOS 0.12.16 (build 34)

- Include the same reviewed 50-achievement Modern Warfare Remastered mapping and validation guards.
- Preserve existing mobile event mappings and event-token/QR/session behaviour.
- The IPA is unsigned; use your existing signing/sideloading method. iOS/iPadOS 17 or later.

## Installation and validation

Install the updated app and reload Modern Warfare Remastered. Scanning for event updates in an older app cannot replace its bundled edition guard.

Both installers are the exact packages tested from source b70c80fc33ddefa05e90fa6b8938da7d18f30ec0:

- [Android checks](https://github.com/thevampirebat/achievement-labs/actions/runs/40375566054): build, lint, unit tests and emulator smoke checks passed.
- [iOS checks](https://github.com/thevampirebat/achievement-labs/actions/runs/40375571435): core tests, device/simulator builds and simulator smoke checks passed.
- Five offline routing regressions passed, including legacy/corrected catalogues and rejection of missing/extra IDs, changed payloads and disabled author data.
- Installer/artifact checksums, packaged mappings and Android signing identity were verified. No account credentials or live achievement-unlock requests were used for validation. Confirm actual Xbox progress after testing.

See BUILD-INFO.json and SHA256.txt for provenance and installer integrity.
