# Achievement Labs — All fork upgrades

This cumulative Windows x64 release includes all enhancements from PRs #1–#5. Download **AchievementLabs.exe** below. Existing settings and saved queues are retained.

## Latest improvements

- Auto Unlock highlights completed rows green and keeps the queue scrollable while running.
- Auto Unlock and title spoofing can run together. Shared presence handling preserves the other operation when one stops.
- Title spoofer **Look up title** works while Auto Unlock runs.
- The Xbox library offers **A-Z, Z-A and Last Played**, remembers the last sort, and refreshes Xbox activity when Last Played is selected.
- Last Played retains dates from initial account loading, preserves selection by title ID, and returns to the top without jumping to the first A-Z title, such as #IDARB.
- Auto Unlock has a separate status tile showing progress, next achievement, next-unlock countdown, estimated total time remaining, and estimated finish day/date/local time. Estimates reflect queue delays and speed; network requests can add time.
- **Get event token** uses Windows account sign-in and a device-bound exchange, checking available accounts against the connected Xbox XUID. Other accounts are rejected before requesting an events token.
- Saving a retrieved token keeps it in the Paste event token box. Tokens remain masked unless revealed; background cache retrieval preserves a Windows account token and manual entries.

## Earlier upgrades included

- Retry already-unlocked event achievements when reviewed mapped event data exists.
- Checkbox multi-selection, Select all/Clear, and sequential batch submission.
- Achievement A-Z/Z-A sorting, filtering, selection preservation, and scroll-crash fixes.
- Call of Duty: Ghosts Xbox One base-game/DLC sections with green dividers and pack filtering.
- Corrected Ghosts DLC achievement mappings, including Hat-Trick; reviewed edition remaps for Infinite Warfare, Modern Warfare Remastered and The Escapists: The Walking Dead. Ambiguous mappings remain disabled, and catalog/payload checks reject unexpected changes.
- Export all achievements with progress, pause/resume, saved account-specific results, and skipping already-scanned titles by default. Exports use Xbox Title ID and available Service Config ID.
- Xbox-recorded playtime shown in hours/minutes, with manual and periodic refresh.
- Heartbeat HTTP diagnostics and a read-only Xbox login check.
- Achievement-page shortcut to Auto Unlock with the title ID filled in.
- Remove selected entries from stopped queues; load saved queues for review before starting.

## Validation and limitations

All nine offline regression groups and the self-contained Windows build passed in [Actions run 37310738033](https://github.com/thevampirebat/achievement-labs/actions/runs/37310738033). The tested source tree matches release source commit `f8bbfc3cd0646ce3bd568782df369febc8138b08`.

Windows account broker availability and actual achievement credit still require testing on your PC. Gaming Services cache retrieval remains experimental. This release does not claim universal DLC grouping, new verified event data for 7 Days to Die, or a guaranteed fix for all presence HTTP 401 errors.

The executable is unsigned and requires Windows 10 build 19041 or newer. The underlying source/application version remains 1.0.3; **fork.2** identifies this cumulative fork release. GitHub's source ZIP and tarball are generated automatically from the release tag.
