# Achievement Labs 1.0.6 — All fork upgrades (fork.1)

Ports our cumulative enhancements onto upstream v1.0.6, including its refreshed build 1.0.6.1. Saved settings, queues and account caches retain their existing paths.

- Adds verified automatic updates with checksums, backups and startup rollback. Updates are restricted to this fork, using matching fork tags and update.json metadata.
- Includes upstream's native GFWL workspace, improved title identification, verified title search, and Windows 8 history/pagination/alias improvements.
- Preserves DLC/hub grouping and collapsible sections, Mythic-style completion indicators and colours, shared totals, legacy progress retention, export-all/checkpoints, library sorting, token presentation/account matching, retry/multiselection, corrected event editions, queue scheduling/removal/failure controls, concurrent spoofing, Windows notifications and compact queue status tiles.
- Includes collector-response diagnostics: HTTP success alone does not confirm collector acceptance or an achievement unlock. Explicit rejection is reported and safe counters are displayed.
- Preserves 15,725 previously usable local achievement recipes across 397 local titles, including all 48 Sonic Forces mappings and the ordinary replacement formats for ESO and Gears of War 4.
- Reflects upstream's published 413-title list: 263 Supported, 147 Testing and 3 Coming Soon. Thirteen advertised mapped titles lack complete recipes/templates in the tagged public source and retain the existing catalogue-service fallback.
- Both mapped 7 Days to Die editions retain upstream's Testing classification. The user confirmed their Xbox One attempts unlocked after a delay of a few minutes; no recipe change was needed for those attempts.
- Xbox 360 profile browsing/backups are included. Signing-dependent achievement edits/save and GPD addition are disabled because the upstream public source omits its signing dependency. No recovered private signing material is packaged.
