# Achievement Labs 1.0.6 — Catalogue and Desktop Improvements (fork.3)

Windows executable version: **1.0.6.3**. Uses the same executable that passed the PR Windows checks; all prior fork improvements are retained.

- Minecraft Xbox One Edition now uses the original app’s catalogue service instead of the bundled Windows/Bedrock recipes. The user confirmed Cupid unlocks with this route.
- New event titles can be retrieved automatically from the original GitHub repo at startup and hourly, with a manual Check now button and opt-out in Settings. Validated additions are cached for offline use and labelled Testing. Existing mappings, edition corrections and remote-only titles are preserved. Unsupported or incompatible entries are skipped; failed downloads retain the cache. This is an additions updater, not replacement of existing event mappings.
- Settings are grouped, with Save all settings at the top. Optional window size and position memory restores within monitor working areas, including taskbar/frame bounds, high-DPI displays and removed-monitor recovery. Optional startup maximization preserves normal placement.
- Enter supports appropriate lookups/searches and token saving. In either queue configuration field, Enter builds the queue for review only when both reference gamertag and Title ID are filled and controls permit it. It does not start unlocking or spoofing.
- Follow-up edition review documents Minecraft Nintendo Switch, Prey and Dishonored 2 as investigation candidates; no speculative remaps added.

Validation: Windows offline desktop/routing regression checks, whole remaining bundled catalogue validation (396 local titles, 15,608 usable achievement recipes and 30,260 strict-JSON payloads), upstream update/cache failure fixtures, window placement cases, updater checks and self-contained EXE packaging. Development tests sent no live Xbox events. Automatically imported titles’ server credit is not verified.

The executable is unsigned. Download AchievementLabs.exe; SHA256.txt and BUILD-INFO.txt accompany it. Release update metadata matches the executable’s 1.0.6.3 version and checksum.
