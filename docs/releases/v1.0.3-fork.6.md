# Achievement Labs — Completion indicators and DLC catalogue (fork.6)

This cumulative release includes all previous fork upgrades and the latest tested improvements. The application source baseline remains 1.0.3; the fork release number identifies these additional upgrades.

- Collapse or expand Base game, DLC and title-update sections by clicking their green headings. Searching exposes matching rows; folding does not remove rows from exports or batch selection.
- Published grouping data now covers 1,324 title lists from the supplied exports, with edition-specific IDs and a separate Call of Duty hub catalogue. Automatic daily catalogue checks and a Settings refresh button keep grouping metadata current without opening cache folders.
- Optional Mythic-style base-completion icons appear beside library achievement counts and on achievement pages. These are local indicators, not official Xbox awards. Saved icon colours and independent visibility settings are supported.
- Optional library backgrounds now indicate 100% completion of the entire achievement list, including DLC and title updates. Fully completed games without DLC or grouping metadata qualify. Completing DLC alone does not highlight games with locked base achievements. Background colours are customizable.
- Corrected Xbox 360/GFWL achievement-page progress: read the definition catalogue and separate earned-achievements list, join exact IDs, support pagination and offline unlocks, and retain known counts when progress is incomplete. Fable III PC and Xbox 360 are labelled separately.
- Account-specific saved exports can supply completion progress. Missing progress can be scanned read-only, one title at a time. Partial unknown lists are not inferred from achievement order or a 1,000G total.
- Settings contains the permanent Export all achievements button and a Debug section for reports, verified-total exports and catalogue checks. Existing legacy export checkpoints are reread once to obtain verified earned progress.
- Confirmed GFWL editions and shared Xbox 360/GFWL achievement lists receive appropriate labels.
- Retained game-page Auto Unlock/Title Spoof shortcuts, Xbox-recorded playtime, search clear buttons, completed-queue removal, concurrent spoofing and auto unlock, queue scheduling/delays/failure controls, Windows notifications, library sorting/shared totals, account-aware token presentation, achievement retry/multi-selection, and edition-specific event mapping corrections.

Download **AchievementLabs.exe** from the release assets to run the app. GitHub's automatic source archives are source code.
