# Achievement Labs Beta — Windows 1.0.8.11

This release brings the desktop Game Session and glass appearance preview into the normal source build.

- Combined title spoofing, game details and Auto Unlock in one Game Session. Library and achievement pages offer a single entry action; title details and eligible Xbox playtime load when opened.
- Full artwork background and shared game image; adjustable glass transparency, blur and colour, custom backgrounds, persistent game art and OLED black.
- Integrated queue tools and status, wider minute inputs, selectable game details and responsive queue height.
- Clearer Library achievement/Mythic sections and completion percentages; fixed the virtualized scrolling crash.
- Home and Library completion summaries based on loaded games, with no extra polling.

Windows is an unsigned self-contained x64 executable. Extract the Windows ZIP and run `AchievementLabs.exe`; keep your existing account settings and saved queues. See GAME-SESSION.md for layout, appearance and count definitions.

Android 0.6.1 and iOS 0.12.3 are unchanged assets retained from v1.0.8-fork.10. The iOS IPA still requires signing. This release does not rebuild the mobile apps.

Validation includes the existing offline enhancement/updater checks, presentation logic checks and packaged UI/scroll checks. Live Xbox sign-in, event delivery and licensing are not exercised by those checks.
