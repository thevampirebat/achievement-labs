# Achievement Labs — Queue notifications and compact layout (fork.7)

This cumulative release keeps all previous fork upgrades and adds the latest auto-unlock and title-spoofer improvements. The application source baseline remains 1.0.3.

- Spoofing failures now notify when startup authorization cannot be read as well as when a heartbeat fails.
- Optional **Stop auto unlock if spoofing fails** cancels the queue and keeps pending entries for resuming. This option works independently of notification settings. Manually stopping spoofing leaves auto-unlock running.
- Optional Windows and in-app notifications report when auto-unlock finishes, including failed-achievement counts. Partial, cancelled and stopped-on-failure queues do not report completion.
- Both new options appear with the other auto-unlock toggles in one wrapping row and persist through **Save settings**. Completion notifications default on; stop-on-spoof-failure defaults off.
- Queue Status and Title Spoofer tiles use tighter padding and spacing, progress and timers beside their headings, and timing details side by side.
- The Start spoofing shortcut has been removed from Auto Unlock. Start spoofing from the Title Spoofer page; its live stats and stop controls remain visible in Auto Unlock.
- All earlier DLC grouping, completion indicators, legacy-progress fixes, library totals and sorting, export, queue scheduling, token handling and achievement mapping upgrades are retained.
