# Achievement Labs — PC 1.0.8.9 / Android 0.6.0 / iOS 0.12.1

**Early beta — bugs are expected.** Features may fail, background sessions may stop, and behavior may differ between platforms. Please start with a small queue and report problems with the app version and error details.

For simplified setup and everyday use, see [Start here](START-HERE.md).

This release brings the standalone mobile apps and the recent desktop improvements together.

## PC 1.0.8.9

- Categorized Settings and the mobile sync shortcut beside Attach Xbox PC app.
- Separate QR modes for sign-in plus event token, sign-in only, and event token only, with adjustable cycling speed.
- Account-specific saved game queues, delay/progress transfer by JSON or QR, and import from shared QR images.
- Existing achievement mapping fixes, DLC/base/update grouping, completion indicators, library sorting, notifications and concurrent Auto Unlock/Title Spoofing remain included.

## Android 0.6.0

- Standalone Xbox library, artwork, profile information, achievement search/sort and locked/unlocked filters.
- Auto Unlock and Title Spoofing with foreground-service notifications, session timers and an Android Home Screen widget.
- Delays displayed in minutes, saved queues per game/account and JSON/QR queue transfer.
- PC sign-in-only QR import preserves an existing event token for the same account.
- APK signed with the permanent release key so compatible installations can update in place.

## iOS / iPadOS 0.12.1

- Standalone iPhone/iPad app with categorized settings, game artwork, profile/completion information, browser sign-in and PC QR sync.
- Saved queues per game/account, JSON/QR queue transfer, sign-in-only QR import and editable queue delays.
- Lock-screen Live Activity and Dynamic Island display spoofing time, the next unlock countdown, game and achievement names.
- Removed the iOS Home Screen widget, its settings and App Groups requirement for compatibility with the current signing setup. Keep the Live Activity extension when signing the IPA.
- iOS event collector fixes and background session options remain included.

## Installing and updating

Windows: extract the Windows ZIP and run AchievementLabs.exe. Android: install the signed APK over a compatible existing installation. iOS: sign the unsigned IPA using your chosen signing service before installing it. No Apple signing identity or profile is included.

## Queue transfer

Pause Auto Unlock before transferring and use the same Xbox account on both devices. Queue transfers include saved games, progress and delays, without sign-in credentials. Imported achievements are checked against Xbox and imported queues require review and Start. PC reads all shared QR images together; it does not use a live webcam. JSON transfer remains available for larger queues. This is manual snapshot sync, not continuous cloud synchronization.

## Status and limitations

A request accepted by an event collector is not proof an achievement unlocked. Refresh Xbox progress before retrying uncertain submissions. iOS background execution is controlled by the operating system; no mode guarantees indefinite execution. A Live Activity timer is a session display, not proof that the process is still running or Xbox recorded playtime. Legacy Xbox 360/GFWL achievements are read-only on mobile. Mythic/base-completion indicators use available local completion evidence.
