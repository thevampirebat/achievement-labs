# Achievement Labs Beta — PC 1.0.8.10 / Android 0.6.1 / iOS 0.12.3

**Early beta — bugs are expected.** Keep an export of important saved queues before updating.

## What changed

- **PC:** Auto Unlock now automatically remembers failure, token-refresh and notification options, speeds, reference gamertags and the build-queue buffer between launches. Preferences are saved separately from game progress and remain after deleting queues. Loading a saved game can still restore that game's saved speed and failure choices.
- **PC, Android and iOS:** Added **Delete saved queue** with confirmation under **Auto Unlock → Saved game queues**.
- Deleting a saved game also removes its loaded queue items/checkpoint so autosave cannot bring it back. Other games and actual Xbox achievements are unchanged.
- Queue deletion requires Auto Unlock to be paused and checks the signed-in account again when confirmed.
- **Android:** Corrected the outdated Settings version label.
- All previous fork features and fixes remain included.

## Downloads and installation

- **PC 1.0.8.10:** Download the Windows ZIP, extract it and run AchievementLabs.exe. The raw executable and update metadata are also included for the existing updater.
- **Android 0.6.1 (version code 9):** Install the APK over your compatible existing installation. It uses the same permanent release signing key.
- **iOS/iPadOS 0.12.3 (build 21):** Download the iOS ZIP or raw unsigned IPA, then sign/install through Signulous. Keep the Live Activity extension.

Each ZIP includes START-HERE.md, RELEASE-NOTES.md and QUEUE-SETTINGS.md. Checksums are in SHA256.txt.

## Saved queues and settings

Expand **Saved game queues**, select a game on PC or find its row on mobile, and choose **Delete saved queue**. Confirm the prompt. Deletion is local; copies previously transferred to another device remain there. Queue transfers still use manual JSON/QR snapshots and the same Xbox account. Loading or importing does not start unlocking.

## Verification and limitations

All three platform workflows passed from the same tested source, and the merged source tree is identical. Checks include Windows offline enhancement/updater tests, Android unit/lint/emulator tests and iOS core tests, device/simulator builds, Live Activity layouts and simulator runtime/background checks. Artifact checksums and package versions were verified; the Android signing certificate was checked.

No authenticated Xbox unlock requests are sent in CI. An accepted event request is not confirmation of an unlock; refresh Xbox progress to verify. Background execution remains OS-controlled, and a visible timer does not prove the process is running or that Xbox recorded playtime.
