# Auto Unlock settings and saved-queue management

PC Auto Unlock now automatically remembers its failure/notification/token-refresh options, speed, reference gamertag, build-queue speed/reference/buffer, stop-on-spoof-failure and completion-notification choices. These preferences are saved separately from game progress and survive deleting a queue. Loading a saved game can still restore that game's saved speed and failure options. Edited game delays retain their existing per-game checkpoint behavior. Queues remain paused until Start is pressed.

On PC, expand **Auto Unlock → Saved game queues**, select a game and choose **Delete saved queue**. On iPhone/iPad and Android, expand **Saved game queues** and use the delete option on that game. Confirm the prompt to delete it. If that game is currently loaded, its loaded items are removed too so autosave cannot recreate the deleted save. Other games and the Xbox account's actual achievements are unchanged. Pause Auto Unlock before deleting. This is a local deletion; copies previously transferred to another device are not deleted remotely.

Candidate versions: Windows 1.0.8.10, Android 0.6.1 (9), iOS 0.12.3 (21). Android's Settings version label is corrected in this build.

Early beta: bugs may remain. Keep an export of important saved queues before testing.
